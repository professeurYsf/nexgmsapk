Fusionne les nombres identiques jusqu'à 4096

🎮 Jeu en pause

Comment jouer

  • Glisse (ou utilise les flèches) pour déplacer toutes les tuiles.
  • Deux tuiles portant le même nombre et la même couleur fusionnent en une seule tuile de valeur double.
  • Atteins la tuile 4096 pour gagner, puis continue ou arrête-toi. Le maximum est 16384 (8192 + 8192).
  • La partie se termine quand la grille est pleine et qu'aucune fusion n'est possible.
